# Dsluo Tap

## How do I install these formulae?

`brew install dsluo/tap/<formula>`

Or `brew tap dsluo/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dsluo/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
